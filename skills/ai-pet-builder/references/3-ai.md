# 阶段 3：接入 AI 大脑

**目标**：宠物用真正的大模型聊天，并且有学生设定的性格。

## 先讲清楚三个概念

- **大模型**：一个能理解和生成文字的 AI 服务，宠物的"大脑"。
- **API 密钥**：使用这个服务的"会员卡号"。谁拿到它，谁就能用你的额度花你的钱，所以**绝不能告诉别人，也不要发在聊天里**。
- **为什么密钥放在服务端**：网页的代码会被下载到每个访问者的手机上，任何人都能看到。所以密钥只放在服务端（`server/chat.ts` 读取它），网页只负责把聊天内容发给服务端转交。

## 学生要做的（默认用 DeepSeek，便宜且国内可直接访问）

1. 打开 https://platform.deepseek.com ，用手机号注册并登录。
2. 在"充值"页面充一点钱。聊天用量很小，**10 元能用很久**。
3. 在"API Keys"页面创建一个密钥，**复制下来，先不要关闭页面**（有的平台只显示一次）。
4. 在项目文件夹里，把 `.env.example` 复制一份，改名为 `.env`（这一步你可以替学生做）。
5. **学生自己**用编辑器打开 `.env`，把密钥粘贴到 `LLM_API_KEY=` 后面，保存。

> 学生想用其他模型（通义千问、豆包、智谱、Kimi 等）也可以：`.env.example` 里列出了各家的接口地址。换的时候要同时改 `LLM_BASE_URL` 和 `LLM_MODEL`，模型名以对方平台的文档为准，并且删掉 `LLM_EXTRA_BODY` 这一行（它是 DeepSeek 专用的设置）。

## 你来做的

1. 确认 `.env` 存在、`LLM_API_KEY` 有值。**不要把值读出来显示给学生，也不要复述它。**
2. 确认 `.gitignore` 里有 `.env`（模板已包含）。告诉学生：这能保证密钥不会被上传到网上。
3. 重启 `npm run dev`（`.env` 改动后开发服务会自动重启，没有重启就手动重启）。
4. 请学生和宠物聊几句，然后检查：
   - 回复有没有体现性格？
   - 有没有用上口头禅？
   - 问它"1+1 等于几"，它应该用宠物的方式表示不懂，而不是认真回答。

## 可选：调整性格

人设提示词在 `server/chat.ts` 的 `systemPrompt` 函数里。学生觉得宠物"不像"时，问他具体哪里不像，再一起改。这一步可以让学生直观感受到"提示词"如何影响 AI 的行为。

## 完成标准

- 聊天回复来自真模型，符合设定的性格。
- 密钥只在 `.env` 里，没有出现在聊天记录或其他文件中。

## 常见问题

- **回复"脑袋转不动了"**：看运行 `npm run dev` 的终端，里面有 `[pet-api]` 开头的报错。
  - 401：密钥错误。
  - 402：余额不足。
  - 404：模型名或接口地址错误。
