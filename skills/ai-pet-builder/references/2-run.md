# 阶段 2：第一次跑起来

**目标**：学生在电脑浏览器里看到自己的宠物页面。

## 步骤

1. 运行 `npm run dev`。这个命令会一直运行，不要关掉它。
   - 如果你的工具能在后台运行命令，就放在后台运行。
   - 不能的话，请学生自己打开一个终端运行，并告诉他这个窗口要一直开着。
2. 请学生用浏览器打开 http://localhost:5173 。
3. 请学生描述看到了什么，应该是：
   - 顶部有宠物的名字和四个圆环（饱食、心情、精力、亲密）。
   - 中间一张卡片写着"还没有宠物视频"。现在还没有形象，这是正常的。
   - 底部有喂食、玩耍、睡觉三个按钮和一个输入框。
4. 请学生依次点**喂食、玩耍、睡觉**，看气泡里的台词是不是阶段 1 写的那些。
5. 请学生在输入框里打一句话发出去。现在回复的是**模拟回复**，因为还没接入 AI。

## 讲解

- `localhost` 的意思是"这台电脑自己"，所以现在只有你能看到这个页面，别人还看不到。
- 四个圆环会随时间变化：放着不管，宠物会慢慢变饿、变困。关掉页面再打开，它会按你离开的时间结算。数据存在浏览器里。

## 完成标准

- 页面能打开，按钮能点，台词正确。

## 常见问题

- **端口被占用**（提示 5173 已被使用）：Vite 会自动换成 5174 等端口，以命令输出里的地址为准。
- **页面空白**：看终端里有没有红色报错，读报错修复。
