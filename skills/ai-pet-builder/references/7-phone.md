# 阶段 7：手机上测试

**目标**：在真实的手机上把所有功能试一遍，发现问题并修好。

## 为什么必须在手机上测

告诉学生：电脑上正常，不代表手机上正常。手机的屏幕尺寸、触摸方式、浏览器限制都不一样。**测试是做产品必不可少的一步，用户不会替你测。**

## 步骤

1. 停掉原来的 `npm run dev`，改为运行 `npm run dev:https`。
2. 在命令输出里找到 `Network` 开头的地址（形如 `https://192.168.x.x:5173`），告诉学生。
3. 请学生：
   - 让**手机和电脑连同一个 WiFi**。
   - 用手机浏览器打开这个地址。iPhone 用 Safari。
   - 出现"不安全"或"证书无效"的提示时，点"高级"→"继续访问"。这是本地测试用的临时证书，正常现象。
4. 把下面的测试清单给学生，请他逐项试完后告诉你结果：

| 功能 | 怎么试 | 预期 |
|---|---|---|
| 画面 | 打开页面 | 宠物在动，没有被顶部或底部遮挡 |
| 摸头 | 点头，或在头上来回划 | 眯眼，冒爱心 |
| 点鼻子 | 点鼻子 | 打喷嚏 |
| 戳身体 | 点身体 | 弹出台词 |
| 喂食、玩耍、睡觉 | 点三个按钮 | 播放对应视频，台词正确 |
| 聊天 | 打字发送 | 宠物回复，嘴巴在动 |
| 朗读 | 右上角喇叭开着时聊天 | 回复被读出来 |
| 声音互动 | 点麦克风，说一句话 | 说完后宠物叫 |
| 摄像头 | 点右上角相机，允许权限 | 对着手机笑、张开手掌、凑近、离开，宠物有反应 |
| 流畅度 | 开着摄像头用几分钟 | 不卡、不烫 |

5. 学生报告问题时，先问清楚现象（最好有截图或录屏），再修复，修好后请他重新测那一项。

## 常见问题

- **手机打不开地址**：
  - 确认手机和电脑连的是同一个 WiFi。
  - Windows 弹出防火墙提示时选"允许"。
  - 公司或学校的网络可能禁止设备之间互相访问，可以改用手机热点：电脑连手机开的热点。
- **麦克风或摄像头没反应**：确认地址是 `https` 开头，并且允许了权限。被拒绝过的话，要到浏览器设置里重新允许。
- **视频不播放**：iPhone 开着低电量模式时可能不自动播放，可以关掉低电量模式再试。

## 完成标准

- 测试清单全部通过，或遇到的问题都已修复。
