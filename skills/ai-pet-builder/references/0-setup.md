# 阶段 0：准备环境

**目标**：学生电脑上能运行这个项目需要的工具。

## 步骤

1. **检查 Node.js**：运行 `node -v`。
   - 显示 `v20` 或更高的版本号：已安装，跳到第 3 步。
   - 提示找不到命令：进入第 2 步。
2. **请学生安装 Node.js**（这一步要学生自己做）：
   - 打开 https://nodejs.org ，下载标着 **LTS** 的版本，双击安装，一路点"下一步"。
   - 装好后**关掉并重新打开 AI 工具**（或终端），再运行 `node -v` 确认。
   - 解释：Node.js 是让电脑能运行这个项目的"发动机"，就像玩游戏前要先装好游戏平台。
3. **安装项目依赖**：在项目文件夹运行 `npm install`。
   - 解释：项目用到了别人写好的"零件"（比如显示页面、识别人脸的工具），这一步是把零件下载下来。
   - 国内网络很慢或失败时，可以改用镜像：`npm install --registry=https://registry.npmmirror.com`。
4. **确认成功**：运行 `npm run build`，看到 `built in` 字样即为成功。

## 完成标准

- `node -v` 显示 v20 或更高。
- `npm install` 和 `npm run build` 都没有报错。

## 讲给学生的一句话

> 做产品的第一步往往不是写代码，而是把"工作台"搭好。专业开发者每次换电脑也要做这一步。
