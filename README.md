# 做一只你自己的 AI 宠物

跟着 AI 一步步做出一只住在手机里的宠物，它能：

- **聊天**：接入大模型，有你设定的性格。
- **被摸**：摸头、点鼻子、戳肚子，都有不同反应。
- **养成**：会饿、会困、会难过，需要你喂食、陪玩、哄睡。
- **听你说话**：你说完话，它会叫着回应你。
- **看见你**：打开摄像头，它会认出你在笑、在挥手、凑太近了。

最后发布到网上，发个链接，朋友用手机就能打开。

**不需要会编程。** 你负责做决定，AI 负责写代码。

---

## 开始之前你需要

| 需要什么 | 用来做什么 | 费用 |
|---|---|---|
| 一台电脑（Windows 或 Mac） | 制作 | |
| 一个 AI 编程工具（Claude Code、Codex、Cursor、Trae 等都可以） | 帮你写代码 | 看工具 |
| [Node.js](https://nodejs.org)（下载 LTS 版本） | 让项目跑起来 | 免费 |
| 一个大模型账号，默认用 [DeepSeek](https://platform.deepseek.com) | 宠物的"大脑" | 充 10 元能用很久 |
| 一个 AI 画图工具（豆包、即梦等） | 画出宠物的样子 | 多数有免费额度 |
| 一个 AI 视频工具（Grok、即梦、可灵等） | 让宠物动起来 | 看工具 |
| 一部手机 | 测试 | |

## 三步开始

1. **下载这个项目**：点页面上的绿色 `Code` 按钮 → `Download ZIP`，解压到一个好找的地方，比如桌面。
2. **用 AI 编程工具打开这个文件夹**。
3. **对 AI 说：**

   > 开始做我的 AI 宠物

AI 会读取项目里的教程，一步一步带你做完。下次接着做时，对它说"继续做我的宠物"，它会从上次停下的地方继续。

## 两条重要提醒

- **API 密钥不要发在聊天里，也不要告诉任何人。** 需要填密钥时，AI 会告诉你把它粘贴到哪个文件。
- **生成图片和视频时用你自己的创意**，不要直接拿网上别人的角色图片。
